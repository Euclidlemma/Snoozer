A snoozer on one date

Today a snoozer repeats every week. This adds a second kind: one date only ("Fri 4 Dec, 13:00–15:00, Study"), picked on a small calendar in the new-snoozer screen. Under the hood it's a snoozer whose first and last date are the same day, so the alarms, the status card, the month marks and the weekly report already handle it. Only the screens change.
